## Where the evidence comes from

Most claims here are checkable from the repository itself:

```bash
git shortlog -sne --all                    # contribution split
git log --all --author=antonin --oneline   # the frontend work, 25–28 July
git log --all --oneline -- mvp             # the parallel Next.js app, later deleted
git branch -a                              # the four stale person-branches
```

Where a claim is a personal recollection rather than something git can confirm, it says so.

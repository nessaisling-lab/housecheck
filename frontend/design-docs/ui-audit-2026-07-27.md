# HouseCheck UI Consistency & Accessibility Audit

**Scope:** all routes (`/`, `/building/:bbl`, `/saved`, `/compare`, `/more`), AgentSheet, Onboarding, Sheet/modals, NavChrome, all shared components. Audit date: 2026-07-27. No code was changed.

**Method:** full read of `index.css` token system, grep-based inventory of every hard-coded color in app code (vendored `components/ui/` excluded), computed WCAG contrast ratios (alpha-composited, not eyeballed), focus-state and heading-order scan.

---

## 🔴 Critical

### C1. No keyboard focus indicators anywhere
- **Where:** all inputs and most buttons — `Home.tsx:109`, `HealthCard.tsx:486`, `AgentSheet.tsx:409`, plus all custom `<button>`s
- **Problem:** every input uses `outline-none` and no component defines a `:focus-visible` style. Keyboard users have zero indication of where focus is. WCAG 2.4.7 failure.
- **Fix:** add a global focus ring, e.g.
  ```css
  :focus-visible { outline: 2px solid var(--hc-canvas-ink); outline-offset: 2px; border-radius: inherit; }
  ```
  (on dark cards: `outline-color: #F5F5F7`). One rule in `index.css` fixes the whole app.
- **Appears elsewhere:** yes — app-wide, the single highest-impact fix in this audit.

### C2. `--hc-canvas-ink-3` (captions/placeholders on light pages) — 2.46:1, FAIL
- **Where:** `index.css:34`; used for captions, helper text, placeholders on the light canvas (Home, Saved, More, Compare)
- **Current:** `rgba(28,28,30,0.42)` on `rgb(215,215,217)` = **2.46:1** (needs 4.5:1)
- **Fix:** darken to `rgba(28,28,30,0.60)` → **4.0:1** (still shy) or `rgba(28,28,30,0.66)` → **4.6:1 PASS**. Note `--hc-canvas-ink-2` at 0.62 is already 4.17:1 — consider merging the two tokens (see M2).

### C3. SpectrumTrack labels + reference line — legacy teal, 2.19:1, FAIL
- **Where:** `SpectrumTrack.tsx:41,58`
- **Problem:** `rgba(47,109,124,0.6)` — a teal from the *old* pre-inversion palette. Contrast 2.19:1 on canvas, and it's the only teal left in the app, clashing with the neutral ink system. The 11px "Below/Above median" labels are unreadable.
- **Fix:** replace with `var(--hc-canvas-ink-2)` (4.17:1, and on-system); reference line `rgba(47,109,124,0.35)` → `rgba(28,28,30,0.35)`.

### C4. Muted grays on canvas — 2.2–2.5:1, FAIL
- **Where:** `StatusPill.tsx:9` default `#8E8E93` (2.27:1); `rgba(58,58,60,0.5)` (2.46:1) used in HealthCard/Compare; `#717182` (unused fallback, SpectrumTrack)
- **Fix:** route all "muted on light canvas" text through the fixed ink token from C2. One token, one contrast guarantee.

## 🟠 High

### H1. On-card 12–13px uppercase labels — 3.60:1 (passes large-text only, fails normal)
- **Where:** `.hc-eyebrow`, `.hc-row-label` (`index.css:165-178`) — `rgba(255,255,255,0.44)` on `#3A3A3C`
- **Problem:** these are 12–13px, i.e. "normal text" under WCAG → need 4.5:1. Currently 3.60:1.
- **Fix:** bump to `rgba(255,255,255,0.55)` → ~4.6:1. Keeps the whisper-quiet look, crosses AA.

### H2. Band colors `concern`/`critical`/`unverified` used as small text — 3.40–4.36:1
- **Where:** score numbers/labels on dark cards (`ScoreRing`, section headers, `StatusPill`)
- **Current:** `#F0743E` 3.93:1, `#F0595C` 3.40:1, `#A0A0A6` 4.36:1 — all pass for large text (≥18px/14px bold) but fail when rendered small.
- **Fix:** either (a) enforce band-colored text at ≥14px semibold only, or (b) brighten: `#F5895C` (~4.6:1), `#F47073` (~4.5:1), `#B4B4BA` (~5.6:1). Strong/solid/mixed already pass (5.2–6.7:1).

### H3. Button system has no shared component — 4+ ad-hoc button styles
- **Where:** rent Check (`HealthCard.tsx` ~472), agent send, sheet close, compare CTA (`.glass-dark`), suggestion chips, result rows
- **Problem:** every button hand-rolls height/radius/padding/color via inline styles; the rent Check is now a `glass-orb` pill while nothing else is; disabled state is `opacity-40` inconsistently applied.
- **Fix:** one `<Button variant="orb|dark|ghost" size="md">` component; migrate the 4 call sites. Disabled opacity standardize at 0.5 (0.4 drops text below contrast on glass).

### H4. Search placeholder white/40 on dark field — 3.54:1
- **Where:** `Home.tsx:109` (`placeholder:text-white/40` on `.glass-field` #2C2C2E)
- **Fix:** `placeholder:text-white/55` → ~4.8:1. (Placeholders technically get WCAG leniency, but this is the app's primary input — worth fixing.)

## 🟡 Medium

### M1. Three overlapping muted-text tokens doing one job
`--hc-canvas-ink-2` (0.62), `--hc-canvas-ink-3` (0.42), plus hard-coded `#8E8E93` / `rgba(58,58,60,0.5)` / teal. **Fix:** two tokens total — `ink-secondary` (0.66, AA-passing) and `ink-faint` (decorative only, never for content text).

### M2. Token duplicates in raw hex
`#3A3A3C` ×7, `#2C2C2E` ×5, `#F5F5F7` ×5, `#48484A` ×3 hard-coded in components — all exact duplicates of `--hc-card`, `--hc-sunken`, `--hc-ink`. **Fix:** mechanical find-replace to `var(--hc-*)`; makes future theme changes one-line.

### M3. Score gradient duplicated by value
`SpectrumTrack.tsx` hard-codes `rgb(228,159,159) / rgb(238,192,149) / rgb(75,205,167)` while band colors live in `lib/score` + tokens. Two sources of truth for the same scale. **Fix:** derive the gradient stops from the band tokens (or document why the spectrum is intentionally softer).

### M4. Heading order
`More.tsx` renders `<h2>`s before the `<h1>` (lines 21, 75); `HealthCard` has three `<h1>`s (204, 220, 354 — loading/error/loaded states, only one renders at a time — acceptable). **Fix:** demote More.tsx section titles' DOM order or restructure; screen-reader outline is currently misleading.

### M5. 158 inline `style={{}}` blocks across 16 files
Concentrated in HealthCard (41), Compare (28), AgentSheet (25). Most are one-off colors/sizes that should be tokens or utility classes. Not urgent, but it's why C2–C4 exist — drift accumulates in inline styles that greps for tokens can't see.

### M6. White spectrum marker on green end — 1.98:1 (non-text)
The marker you just made white fails the 3:1 non-text target at the green end of the gradient. It has a drop shadow which helps; adding a 0.5px `rgba(0,0,0,0.3)` outline would formally pass. Low real-world impact — your call.

## 🔵 Low

- **L1.** shadcn HSL token block (`--background`, `--primary`…) coexists with `--hc-*` tokens but is barely used by app code — dead weight that confuses which system is authoritative.
- **L2.** `@supports not (backdrop-filter)` fallback turns cards **white** (`rgba(255,255,255,0.94)`) while card text stays white → invisible text in old browsers. Nearly extinct scenario, but the fallback should be `var(--hc-card)`.
- **L3.** `text-[11px]`–`text-[13px]` used in ~10 places with ad-hoc tracking — consolidate into the existing `.hc-eyebrow`/`.hc-row-label` + one `.hc-caption` class.
- **L4.** Icon-only buttons (agent orb, sheet close, nav) have `aria-label` ✅ — but bottom-nav `NavLink`s rely on icons + text that's visually tiny; verify 44px targets (orb is 56px ✅, nav items ~44px ✅).
- **L5.** `#D04A1E`, `#C7272B`, `#B7791F`, `#7DA629` in `lib/score` (circle colors) are a *fourth* red/amber/green set alongside band tokens, spectrum gradient, and shadcn destructive — consolidate to band tokens.

## Final recommendations

**Ten changes first:** C1 focus ring → C2 ink-3 → C3 SpectrumTrack teal → C4 StatusPill gray → H1 eyebrow alpha → H4 placeholder → H2 band small-text rule → M4 heading order → M2 hex→token sweep → H3 Button component.

**Proposed palette (simplified):** keep the existing system, just fix alphas —
`canvas #D7D7D9 · ink .94/.66/.42* (*decorative only) · card #3A3A3C · sunken #48484A · on-card #F5F5F7 / white .66 / .55 · bands #4CC66A #A6D65E #E0A83E #F5895C #F47073 #B4B4BA`

**Typography scale:** 34 display / 24 page title / 20 section / 17–15 body / 13 eyebrow (uppercase .1em) / 12 label (uppercase .08em) / 11 caption — already 90% true; codify as classes.

**Button variants:** `orb` (primary CTA, glass), `dark` (`.glass-dark` pill), `ghost` (text + chevron rows), all 44px+ height, `disabled:opacity-50`.

**Implementation order:** index.css token fixes (C1, C2, H1 — one file, biggest a11y gain) → SpectrumTrack/StatusPill component fixes → placeholder & heading fixes → Button consolidation → token sweep → palette consolidation in lib/score.

**Files likely to change:** `index.css`, `SpectrumTrack.tsx`, `StatusPill.tsx`, `Home.tsx`, `More.tsx`, `HealthCard.tsx`, `Compare.tsx`, `AgentSheet.tsx`, `lib/score.ts`, new `components/Button.tsx`.
